## What's new since 0.3.0

- **Your own library.** Games are stored in Room, so they survive process death and app updates. A full uninstall is restored by re-scanning the same folder.
- **Scan a games folder.** `ADD GAMES FOLDER` uses SAF with a persisted read grant. Re-scans upsert by stable id, preserve covers and pin links, and never auto-delete rows.
- **Game details.** Title, engine, WAD version and location; explicit links to Butterscotch pins, cover art, and a Remove that never touches the game folder.
- **Offline RPG Maker MV/MZ** through ADR-0007: `WebViewAssetLoader` serves SAF documents under Android's reserved origin with no `INTERNET` permission, no localhost server and no copy.
- **Engine honesty.** Ren'Py, LÖVE and ScummVM are shown as detected but not hosted.
- **MIT licence** and no third-party branding in source or build.

## Checks that passed

- Host gate: 19 detector + 3 Room mapping + 7 runtime + 35 app tests, debug APK built, signed release APK built.
- No `INTERNET` permission; `:detect` remains pure Kotlin/JVM; no game data in the repository.

## Not verified on hardware

SAF grant flows, covers, pin linking, the offline WebView route, `GameDaoTest`,
MT-01…MT-40 and all compatibility numbers. Use `tools/device_checks.sh` on a
workstation with adb and record results in [COMPATIBILITY.md](../COMPATIBILITY.md).

## Known limitations

Encrypted `.rpgmvp`/`.rpgmvo` assets are not decrypted. Save export is deferred.
SVG assets are served as octet-stream until a sanitising policy exists. No performance
numbers are claimed until they are measured.

## Install note

Signed with the repository's local release key; application id is unchanged. If Android
refuses the update because of a different signing key, uninstall first — that clears the
library, folder grants and pins, so re-scan and re-pin afterwards.
